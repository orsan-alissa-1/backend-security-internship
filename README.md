# Backend Development and Application Security Internship

Documentation of my six-week backend development internship at nanoVoltz in the UAE, completed as part of my BSc in Cybersecurity Engineering at Abu Dhabi University.

The internship involved developing NestJS backend modules for a point-of-sale application, followed by work on authentication and two-factor authentication.

## My Work

- Implemented CRUD modules for Taxes, Modifiers, Order-Types, Customers, and Discounts.
- Created Mongoose schemas and DTOs for database modelling and input validation.
- Added error handling and tested API success and failure cases using Postman and Hoppscotch.
- Implemented signup and login using bcrypt password hashing and expiring JWTs.
- Configured authentication cookies and a global authentication guard.
- Added TOTP two-factor authentication, including setup, verification, enabling, disabling, and login checks.
- Participated in the team's Git workflow and code reviews.

Other team members handled Helmet and throttling configuration.

## Technologies

TypeScript, NestJS, MongoDB, Mongoose, JWT, bcrypt, Speakeasy, Postman, Hoppscotch, Git, and Miro.
